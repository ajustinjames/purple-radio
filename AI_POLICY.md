# AI usage and contribution policy

## What's AI-generated in this repository

Code in this repository is written with AI coding agents, then reviewed and tested by the maintainer. The same goes for the written documentation that accompanies it, such as the PRD, architecture notes and READMEs.

Everything else is either open source, with its source and license recorded, or made personally by the maintainer. No AI-generated creative assets are in the repository or the app.

## Contribution rules

AI assistance is allowed for code, tests, documentation, research, and review. Contributors remain responsible for the accuracy, security, maintainability, and licensing of what they submit. Review and test AI-assisted code to the same standard as any other contribution.

Do not add AI-generated creative assets to this repository or the app. This includes images, logos, icons, illustrations, textures, video, voices, music, sound effects, and similar visual or audio material. The rule applies regardless of file format, including assets represented as SVG or other code.

HTML and CSS mockups of the app's screens, such as [the watch screen mockups](docs/mockups/watch-screens.html), are code and may be AI-generated. They lay out text, plain shapes, and system fonts to show structure. They must not contain or embed generated artwork, and artwork they stand in for must still follow this policy.

Use original human-created assets or appropriately licensed human-created third-party assets, and keep the source and license information needed to use them. AI may help write code that implements the interface; that permission does not extend to generating the creative assets displayed or played by the interface.

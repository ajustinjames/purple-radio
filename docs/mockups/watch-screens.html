Purple Radio: watch screen mockups

A layout sketch of each screen in the core journey, for reviewing layout and copy before the SwiftUI views are built (#33). It isn't a pixel-accurate watchOS rendering. Shapes stand in for artwork, the QR code is a non-scannable placeholder, and channel names are invented.

Notes in purple are open questions.

Sign-in

Shown when signed out. Uses Twitch's device code flow: the watch shows a QR code for the verification URL and the short code, and the listener approves in a browser on another device (#19).

Followed streams

The main screen once signed in: followed channels that are live now (#20). Tapping a row starts its audio and opens Now Playing.

Now playing

Opens when a stream is chosen. Live audio can't pause and resume where it left off, so the main control is Stop (#21). The Digital Crown sets the volume. Listening continues after leaving the app (#23).

Account

The signed-in account and sign-out (#19). No other account management is in scope.

About this page

  • Screen sizes are watchOS points for the 46mm and 42mm Series 10 and later displays.
  • Text uses SF Compact when it's installed and falls back to the system font, so line breaks may differ from the watch.
  • The accent colour is a placeholder; the app's AccentColor asset isn't set yet.
  • Code only: no images, icons or logos. See the AI policy.
